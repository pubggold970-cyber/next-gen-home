# REALISTIC HOME CRAFT — Next Gen Home

A first browser-playable 3D home-building prototype, separate from the QZIX project.

## Run
Open `index.html` on a phone or desktop with an internet connection (Three.js is loaded from jsDelivr).

## Prototype features
- 3D modern room with orbit camera (drag to look around)
- Explore mode and Build mode
- Place sofa, bed, coffee table, plant, floor lamp, and TV
- Rotate furniture, remove the last placed item, change wall color
- Save the room locally in the browser

## Next development stages
1. Third-person player movement and collision
2. Multiple home layouts and exterior environment
3. Two-player online co-building with owner/editor permissions
4. Voice, text chat, and emotes
5. Android app packaging and performance testing

This is an early prototype, not yet an online multiplayer game or a published Android app.
